# תיק המשפחה 📁

אפליקציית ניהול מסמכים משפחתית - ביטוחים, פיננסים, זיכויים, קבלות ועוד - עם מעקב הוצאות/הכנסות ולוח שנה עברי. נבנתה כ-PWA שמתקינים ישירות למסך הבית באייפון (או כל טלפון אחר), ב-$0 עלות חודשית.

## הסטאק

| שכבה | טכנולוגיה | עלות |
|---|---|---|
| פרונטאנד + backend | Next.js 16 (App Router), פרוס ל-Vercel | חינם |
| מסד נתונים | MongoDB Atlas (טיר M0) | חינם |
| אימות | Auth.js (NextAuth) עם Credentials, JWT | חינם |
| אוטומציית תשלומים חודשיים | GitHub Actions (cron חודשי) | חינם |
| חגי ישראל | Hebcal API (ציבורי) | חינם |

כל הנתונים - כולל **קובצי הבינארי עצמם** (לא רק מטא-דאטה) - נשמרים ב-MongoDB תחת החשבון שלך בלבד, ללא תלות בשום צד שלישי.

## הקמה מאפס

### 1. מסד נתונים - MongoDB Atlas

1. הרשם ב-[mongodb.com/cloud/atlas](https://www.mongodb.com/cloud/atlas) וצור פרויקט חדש.
2. צור Cluster מטיר **M0 (Free)**.
3. תחת **Database Access** - צור משתמש עם סיסמה.
4. תחת **Network Access** - הוסף `0.0.0.0/0` (כדי ש-Vercel יוכל להתחבר; אין IP קבוע בטיר החינמי).
5. לחץ "Connect" → "Drivers" והעתק את ה-connection string (מתחיל ב-`mongodb+srv://`).

### 2. הרצה מקומית

```bash
git clone <כתובת ה-repo שלך>
cd family-docs
npm install
cp .env.example .env.local
```

מלא ב-`.env.local`:
- `MONGODB_URI` - ה-connection string מ-Atlas (הוסף בסופו שם database, לדוגמה `/familydocs`)
- `AUTH_SECRET` - הרץ `openssl rand -base64 32` והדבק את הפלט
- `CRON_SECRET` - מחרוזת אקראית נוספת (לדוגמה גם עם `openssl rand -base64 32`)
- `RESEND_API_KEY` - מפתח API מ-[resend.com](https://resend.com) (טיר חינמי מספיק), לשליחת קוד האימות הדו-שלבי לאזור הניהול
- `ADMIN_OTP_FROM_EMAIL` - כתובת שולח מאומתת ב-Resend (לדוגמה `אזור ניהול <onboarding@resend.dev>` לבדיקות, או דומיין משלך לאחר אימות)

```bash
npm run dev
```

**אין הרשמה עצמית.** יצירת משתמשים והקצאתם ל-workspace-ים נעשית אך ורק דרך אזור הניהול (`/admin/login`). כדי ליצור את משתמש ה-admin הראשון ולבצע הגירה חד-פעמית של נתונים קיימים ל-workspace הראשון:

```bash
node scripts/migrate-to-workspaces.js --admin-email=you@example.com
```

הסקריפט יוצר workspace ראשון בשם "המשפחה" (ניתן לשינוי עם `--name="שם אחר"`), משייך אליו את כל המשתמשים הקיימים, מתייג את כל המסמכים/האירועים/המשימות הקיימים אליו, ומסמן את המשתמש עם האימייל שסופק כ-admin. בטוח להרצה כמה פעמים. אם עדיין אין משתמשים כלל, ניתן ליצור משתמש ראשון ישירות מ-MongoDB Atlas (Collections → `users`) או דרך `mongosh`, ואז להריץ את הסקריפט כדי לסמן אותו כ-admin וליצור עבורו workspace.

לאחר מכן היכנס לאזור הניהול ב-`/admin/login` עם האימייל/סיסמה של אותו משתמש (יישלח קוד אימות למייל), וצור/שייך משתמשים ו-workspace-ים נוספים.

שכחת את הסיסמה? אפשר לאפס אותה בכל שלב (גם לפני שיש admin) עם:

```bash
node scripts/reset-password.js --email=you@example.com --password="סיסמה חדשה"
```

### 3. פריסה ל-Vercel (חינם)

1. הרשם ב-[vercel.com](https://vercel.com) עם GitHub.
2. "Add New Project" → בחר את ה-repo הזה.
3. תחת Environment Variables הוסף את חמשת המשתנים מ-`.env.local` (עם ה-URI האמיתי, לא placeholder).
4. Deploy.

בסיום תקבל כתובת כמו `https://family-docs-yourname.vercel.app`.

### 4. התקנה על מסך הבית באייפון

1. פתח את הכתובת שקיבלת מ-Vercel ב-**Safari** באייפון.
2. לחץ על כפתור השיתוף (הריבוע עם החץ) → "הוסף למסך הבית".
3. האפליקציה תופיע כאייקון רגיל שנפתח במסך מלא, בלי סרגל כתובות.

חזור על זה בכל טלפון של בן משפחה.

### 5. אוטומציית תשלומים חודשיים (אופציונלי אך מומלץ)

כדי שהמערכת תיצור אוטומטית רשומת הוצאה בתחילת כל חודש עבור מסמכים עם "תשלום חודשי":

1. ב-GitHub, בעמוד ה-repo → Settings → Secrets and variables → Actions.
2. הוסף שני secrets:
   - `APP_URL` - כתובת האפליקציה שלך מ-Vercel (בלי `/` בסוף)
   - `CRON_SECRET` - **בדיוק אותו ערך** שהזנת ב-Vercel
3. ה-workflow ב-`.github/workflows/monthly-expenses.yml` ירוץ אוטומטית פעם בחודש. אפשר גם להריץ ידנית מטאב "Actions" ב-GitHub → "Monthly Expenses Automation" → "Run workflow".

### 6. התראות Push (אופציונלי)

כדי לאפשר התראות קופצות למכשירים (על משימות באיחור, תאריכי יעד מתקרבים, ותזכורות חודשיות - ראו "אזור אישי" באפליקציה):

1. ייצר זוג מפתחות: `npx web-push generate-vapid-keys`.
2. הוסף ב-Vercel (Environment Variables) ובקובץ `.env.local` המקומי:
   - `NEXT_PUBLIC_VAPID_PUBLIC_KEY` - המפתח הציבורי מהפלט
   - `VAPID_PRIVATE_KEY` - המפתח הפרטי מהפלט (סודי - לא לחשוף)
   - `VAPID_SUBJECT` - כתובת מייל ליצירת קשר, לדוגמה `mailto:you@example.com`
3. כדי שההתראות היומיות (משימות/תאריכי יעד/תזכורות חודשיות) באמת יישלחו, צריך גם cron יומי - בדיוק כמו תשלומים חודשיים (שלב 5 למעלה), אבל עם ה-workflow `.github/workflows/daily-reminders.yml` (רץ אוטומטית כל יום; אותם שני secrets `APP_URL`/`CRON_SECRET` משמשים גם אותו, אין צורך להגדיר שוב).
4. בלי שלבים 1-2, האפליקציה ממשיכה לעבוד כרגיל - רק כפתור "הפעלת התראות" באזור האישי יציג שגיאה.
5. **הערה ל-iPhone:** התראות Push בדפדפן נתמכות ב-iOS רק מגרסה 16.4 ואילך, ורק כשהאפליקציה **מותקנת למסך הבית** (לא בטאב Safari רגיל) - ראו שלב 4 למעלה.

## מגבלות ידועות

- **גודל קובץ מקסימלי: כ-11MB** (מגבלת מסמך MongoDB). מתאים למרבית הסריקות/PDF-ים/תמונות, לא לסרטונים או קבצים כבדים.
- הטיר החינמי של MongoDB Atlas מוגבל ל-512MB אחסון כולל - מספיק בנוחות לשימוש משפחתי (עד 10 משתמשים) לאורך זמן רב.
- הרשאות הן פר-workspace בלבד (גישה מלאה לכל workspace שהמשתמש שויך אליו, ללא הבחנה בין צפייה לעריכה בתוך אותו workspace).

## מבנה הפרויקט

```
src/
  app/                 עמודים (App Router) + API routes
  components/          רכיבי React (טופס העלאה, לוח שנה, כרטיסי מסמך...)
  lib/
    models/            סכמות Mongoose (Document, File, User, CalendarEvent, Task, SubCategory, Workspace, WorkspaceMembership)
    categories.ts       הגדרת הקטגוריות ותתי-הקטגוריות
    auth.ts             הגדרת Auth.js (כניסה רגילה + כניסת admin עם 2FA)
    mongodb.ts           חיבור למסד הנתונים
    resend.ts            שליחת קוד אימות (2FA) למייל האדמין
scripts/
  migrate-to-workspaces.js   הגירה חד-פעמית למבנה multi-tenant + יצירת admin ראשון
  reset-password.js          איפוס סיסמה של משתמש קיים (למשל אם שכחת את סיסמת ה-admin)
  move-workspace-data.js     העברת כל התוכן (מסמכים/יומן/משימות/תתי-קטגוריות) מ-workspace אחד לאחר
  force-assign-workspace.js  שיוך כפוי וללא תנאי של כל התוכן הקיים ב-DB ל-workspace יעד אחד (ראו אזהרה למטה)
.github/workflows/     אוטומציית ה-cron החודשי (תשלומים) והיומי (התראות push)
```

## אזור ניהול (admin)

- כניסה ב-`/admin/login`, בשני שלבים: אימייל+סיסמה → קוד בן 6 ספרות שנשלח למייל (בתוקף ל-10 דקות) → כניסה.
- הרשאת הגישה לאזור הניהול בתוקף ל-48 שעות בלבד מרגע אימות הקוד, בנפרד מההתחברות הרגילה לאפליקציה (שנשארת מחוברת הרבה יותר זמן, כברירת המחדל). אחרי 48 שעות צריך לעבור את זרימת ה-2FA מחדש כדי לגשת לאזור הניהול - גם אם עדיין מחוברים לאפליקציה הרגילה בלי צורך בכניסה חדשה.
- רק משתמש עם `role: "admin"` יכול להיכנס; ההגדרה נעשית ע"י סקריפט ההגירה או ישירות במסד הנתונים.
- מאזור הניהול ניתן ליצור workspace-ים, ליצור משתמשים חדשים (אין הרשמה עצמית), לשייך משתמשים ל-workspace-ים ולהגדיר לכל משתמש שם תצוגה מותאם בכל workspace (למשל "טל" יוצג כ"דן" ב-workspace מסוים).
- משתמש רגיל רואה ויכול לערוך מידע רק ב-workspace-ים שהוא שויך אליהם; אם הוא משויך ליותר מאחד, מוצג בורר workspace בכותרת העליונה.
- תתי-הקטגוריות המוצעות בקטגוריית "כללי" (לדוגמה שמות בני המשפחה) ניתנות להתאמה אישית פר-workspace, מעמוד ה-workspace באזור הניהול.
- אם תוכן קיים "נחת" בטעות ב-workspace הלא נכון (למשל אם הרצת את סקריפט ההגירה עם workspace לא מתאים כבר קיים), אפשר להעביר אותו בעזרת `node scripts/move-workspace-data.js --from="שם מקור" --to="שם יעד"`.
- אם כל התוכן הקיים ב-DB שייך בפועל למשפחה אחת בלבד (למשל מסמכים שהועלו לפני בניית מנגנון ה-workspace-ים, וכרגע לא ברור/לא רלוונטי לאיזה workspace הם משויכים), אפשר "לנעול" את כולם בכוח ל-workspace יעד אחד עם `node scripts/force-assign-workspace.js --to="שם היעד"`. **שימו לב:** בניגוד ל-`move-workspace-data.js`, הסקריפט הזה דורס ללא תנאי את ה-workspaceId על כל רשומה קיימת בכל הקולקציות (לא רק על אלו שבworkspace מסוים) - להריץ רק כשבטוחים שכל התוכן הקיים אכן שייך ליעד הזה.
- כפתור "רענון" בכותרת העליונה מוצג לכל המשתמשים; כפתור "מעבר לאזור ניהול" (ליד כפתור ההתנתקות) מוצג רק למשתמש admin.
- כל משתמש (גם לא-admin) יכול ללחוץ על אייקון המשתמש בכותרת ("שלום, ...") כדי להגיע ל"אזור אישי" (`/profile`) ולעדכן שם וסיסמה בעצמו, בלי לערב admin.
- אייקון חיפוש בכותרת העליונה (`/search`) מחפש בכל ה-workspace הפעיל בבת אחת - מסמכים (כותרת/הערות/תת-קטגוריה/שדות מותאמים אישית), משימות, אירועי יומן, ושמות מוצרים ברשימות קניות.
- בעמוד הראשי של אזור הניהול יש כפתור "הורדת גיבוי מלא (ZIP)" - מוריד קובץ אחד עם כל הנתונים של כל ה-workspace-ים (JSON לכל סוג רשומה, פלוס תיקיית `files/` עם הקבצים הבינאריים המקוריים), בלי סיסמאות. שימושי לגיבוי/שמירה מקומית.
- באזור האישי אפשר גם להפעיל התראות push למכשיר (דורש הגדרה חד-פעמית - ראו "התראות Push" למעלה) ולהגדיר תזכורות חודשיות חוזרות (למשל "להעלות תלוש שכר", ביום קבוע בחודש). כל מי שהפעיל התראות מקבל גם התראה אוטומטית על משימה שהגיע/עבר תאריך היעד שלה, ועל מסמך עם תאריך יעד שמגיע היום או בעוד 3 ימים.
- בעמוד "קטגוריות" יש אריח "האפליקציות שלי" (`/apps`) עם קישורי הפעלה מהירה לאפליקציות חיצוניות (כרגע: Max, בנק דיסקונט, Cal) - לחיצה פותחת את האפליקציה הרשמית אם מותקנת, אחרת את האתר. כדי להוסיף/לשנות אפליקציה, עורכים את `src/lib/externalApps.ts`.
- אפשר לייבא הוצאות/הכנסות בתפזורת מקובץ CSV **או Excel (.xlsx)** (למשל היסטוריית עסקאות שהורדת מ-Max) דרך "ייבוא הוצאות מקובץ" בדשבורד (`/import`) - שני הפורמטים נתמכים ישירות, בלי צורך בהמרה ביניהם. אין חיבור ישיר/אוטומטי לחברת האשראי - זה ייבוא ידני: מורידים קובץ עסקאות, מתאימים עמודות (תאריך/שם/סכום), ומייבאים. המערכת מדלגת אוטומטית על רשומות שכבר קיימות (לפי תאריך+סכום+שם) כדי שאפשר יהיה להעלות שוב קובץ עם חודשים חופפים בלי כפילויות.
- באירועי יומן ובמשימות אפשר לבחור צבע בעת היצירה (מתוך פלטה קבועה, `src/lib/itemColors.ts`) ולערוך (כותרת/תאריך/הערות/צבע) בכל שלב אחרי היצירה, דרך כפתור העיפרון בשורת הפריט.
- לכל רשומה (מסמך/הוצאה/הכנסה) אפשר לצרף כמה קבצים, לא רק אחד - גם בעת היצירה וגם בכל שלב אחרי כך, מעמוד הרשומה ("קבצים מצורפים"). אפשר גם להסיר קובץ בודד מרשומה בלי למחוק את כולה.
- יש אריח "קניות" (`/shopping`) בעמוד הקטגוריות - לא מסמך רגיל אלא רשימת קניות ייעודית: אפשר לפתוח רשימה חדשה לכל יום/ביקור קניות, להוסיף בה מוצרים (שם, כמות - ברירת מחדל 1, ותמונה אופציונלית לצפייה בזמן הקניות בלי צורך בהורדה), לערוך/להסיר מוצר, ולסמן מוצר כ"נוסף לעגלה". רשימה שבה כל המוצרים סומנו עוברת אוטומטית ל"הושלמו".

## פיננסים - מקום מרוכז לכל הכסף

בקטגוריית "פיננסים" כל רשומה היא פריט כסף (חשבון, קרן, קריפטו, הלוואה...):
שם פלטפורמה, סכום נוכחי (ניתן לעדכון מהיר מהרשימה בעזרת העיפרון), רווח צפוי (%),
עמלה (%), סכום יעד עם פס התקדמות, קישור לפלטפורמה והערות. בראש העמוד: סה"כ נטו
(נכסים פחות התחייבויות), עוגה לפי רשומה או לפי סוג, ולכל רשומה השינוי מהעדכון
הקודם ותאריך העדכון האחרון. היסטוריית הסכומים (50 עדכונים אחרונים) נשמרת בשדה
`amountHistory`. התחייבות מסומנת בתיבת "זו התחייבות / חוב".

## אזור אישי (admin בלבד)

בעמוד "קטגוריות" מופיע אריח "אזור אישי" רק למשתמש עם תפקיד admin. הוא מוביל ל-`/personal`
עם קישורים לפרופיל ולאזור הניהול. בכותרת העליונה הטקסט "שלום, ..." מוסתר במסכים צרים
כדי שכפתורי החיפוש/פרופיל/ניהול לא ייחתכו.
